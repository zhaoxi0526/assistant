# 助手应用 (Assistant App)

## 项目概述

这是一个基于Android平台的辅助应用程序，主要功能是通过无障碍服务自动读取短信并将其转发到微信。该应用旨在实现短信内容的自动转发，无需手动操作。

## 技术栈

- **开发语言**: Java
- **目标平台**: Android (最低支持API 24，目标API 34)
- **构建工具**: Gradle (版本 8.10.0-alpha05)
- **编译SDK**: Android SDK 34

## 核心功能

### 1. 短信读取与显示
- 请求并获取短信读取权限
- 显示设备上的短信历史记录
- 实时监听新短信接收

### 2. 微信自动发送
- 通过无障碍服务自动启动微信
- 自动搜索指定联系人
- 将短信内容发送给指定微信联系人
- 自动返回并退出微信

### 3. 配置管理
- 用户可配置触发关键词
- 设置目标微信ID
- 开启/关闭功能开关
- 保存和加载配置

## 主要组件

### MainActivity
- 应用主界面，包含短信列表和配置选项
- 提供权限请求和配置保存功能
- 测试微信连接功能

### WeChatAutoSendService
- 核心无障碍服务，负责自动化操作
- 自动启动微信、搜索联系人、发送消息
- 处理不同界面状态转换

### SmsHelper/SmsAdapter/SmsModel
- 短信数据访问和展示组件
- 提供短信读取和格式化功能

### WeChatAutoSenderConfig
- 应用配置管理，使用SharedPreferences存储设置

### SmsReceiver
- 短信接收广播接收器，实时监听新短信

## 架构特点

1. **无障碍服务驱动**: 使用Android无障碍服务实现UI自动化
2. **状态机设计**: 服务内部采用状态机模式管理操作流程
3. **跨应用交互**: 与微信应用进行深度集成
4. **配置持久化**: 使用本地存储保存用户配置

## 权限需求

- READ_SMS: 读取短信内容
- RECEIVE_SMS: 接收短信广播
- READ_PHONE_STATE: 读取手机状态
- POST_NOTIFICATIONS: 发送通知 (Android 13+)
- BIND_ACCESSIBILITY_SERVICE: 绑定无障碍服务
- FOREGROUND_SERVICE: 前台服务权限

## 使用场景

该应用适用于需要自动转发短信到微信的场景，例如：
- 服务器报警信息自动转发到微信
- 银行交易提醒自动发送到微信
- 验证码自动转发到微信

## 注意事项

- 需要用户手动开启无障碍服务权限
- 由于Android安全限制，可能在不同手机品牌上有兼容性差异
- 应用需要持续运行以监听短信和执行自动化操作
